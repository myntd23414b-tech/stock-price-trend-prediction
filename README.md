# DỰ BÁO XU HƯỚNG GIÁ CỔ PHIẾU BẰNG MACHINE LEARNING

## 1. Giới thiệu dự án
Dự án ứng dụng các thuật toán Machine Learning để phân tích dữ liệu tài chính và dự báo xu hướng giá cổ phiếu.

Đồ án tập trung vào việc thu thập, xử lý, phân tích dữ liệu, xây dựng mô hình dự báo và đánh giá hiệu quả của các thuật toán.

## 2. Công nghệ sử dụng
- Ngôn ngữ lập trình: Python
- Xử lý dữ liệu: Pandas, NumPy
- Machine Learning: Scikit-learn
- Trực quan hóa dữ liệu: Matplotlib
- Môi trường thực hiện: Jupyter Notebook

## 3. Quy trình thực hiện
1. Chuẩn bị và làm sạch dữ liệu cổ phiếu.
2. Thống kê mô tả và phân tích khám phá dữ liệu (EDA).
3. Phân tích mối tương quan giữa các biến.
4. Xây dựng và so sánh sáu mô hình Machine Learning:
   - Logistic Regression
   - K-Nearest Neighbors (KNN)
   - Gaussian Naive Bayes
   - Decision Tree
   - Random Forest
   - Linear SVM
5. Sử dụng Walk-forward Validation và GridSearchCV để đánh giá, tối ưu mô hình.
6. Đánh giá kết quả thông qua Macro F1, ROC-AUC và ma trận nhầm lẫn.

## 4. Kết quả và nhận xét
- Thực hiện so sánh hiệu quả dự báo của sáu thuật toán.
- Trực quan hóa kết quả và phân tích mức độ quan trọng của các biến.
- Đánh giá hiện tượng overfitting và khả năng tổng quát hóa của mô hình.
- Nhận diện những hạn chế khi dự báo biến động giá cổ phiếu bằng Machine Learning.
